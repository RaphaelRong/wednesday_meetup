# 💡 《流浪电器》：唤醒沉睡的灵魂

## 🌟 项目简介

嘿，朋友，
请你环顾一下四周，或者回忆家中的某个角落。

那里是否有一个不再转动的电风扇，曾为你带来整个夏天的清凉？
是否有一个静静沉睡的电饭锅，曾煮出过无数碗温暖的米饭？
是否有一台落满灰尘的旧CD机，曾在无数个夜晚用音乐和故事陪伴你？

它们曾是你生活中忠实的伙伴，承载着时光的痕迹和独一无二的记忆。当它们老去、损坏，难道只能被遗忘在角落，或成为冰冷的电子垃圾吗？

我们相信，万物皆有灵，记忆不该被丢弃。

为此，我们正式发起 游牧电器计划！

这是一个为废旧电器赋予第二次生命的过程。我们不只是修理，更是“重生”。
写一份简历，向我们介绍一下你的这位“电器老友”。
我们将发动社区的小伙伴们，集体对他进行改造。然后让他开启一段新的旅程。找到新的归宿。

现在，希望你能接受这份邀请，成为这场奇妙旅程的一部分！

🔌 如果你有一位想要“托付”的电器老友：
它不必完美，甚至可以已经无法工作，但我们希望它拥有一个与你之间的故事。
请为它填写一份**[电器灵魂档案]，拍下它的“身份照”**，告诉我们它的名字、性格和与你的回忆。我们将评估

💡 如果你是热爱创造的“魔法师”：
无论你擅长电路、木工、编程，还是仅仅拥有无限的奇思妙想，我们都欢迎你成为**[改造志愿者]**。加入我们，亲手将这些沉睡的灵魂唤醒，赋予它们全新的形态与使命。

点击 [项目主页链接] 了解详情并加入我们。

计划目标

- 收集旧电器：收集至少5个具备故事的废旧电器
- 电器档案：所有废旧电器必须有名字、MBTI、以及与主人之间的故事
- 推广可持续发展：展示 upcycling（升级再造）的无限可能性
- 提升社区参与度：吸引拥有DIY兴趣和创新意识的社区成员参与
- 持续汇报：利用独特的"拟人化故事"进行持续汇报

## 🔌 如何参与

### 1. 捐赠你的"老朋友"

如果你有闲置或损坏的电器想要捐赠，请：

1. 📝 填写[电器灵魂档案](./submissions/appliance-profile-template.md)
2. 📸 拍摄电器的"身份照"
3. 📤 提交到[投稿区](./submissions/)
4. ⏳ 等待我们的评估和接收通知

### 2. 成为创客志愿者

如果你有技术背景或创客经验，欢迎加入我们的改造团队：

1. 📋 查看[项目进度](./projects/)了解当前改造项目
2. 💡 提出你的改造想法
3. 🔧 参与实际改造工作
4. 📝 记录改造过程
